\# AutoLoc



\## 1. Présentation du projet



AutoLoc est une application de gestion et de location de véhicules.

Elle permet de faciliter la gestion des véhicules, des clients, des agences

et des opérations de location.



\## 2. Objectifs



\- Gérer les clients

\- Gérer les véhicules

\- Gérer les agences

\- Gérer les locations

\- Suivre les opérations de location

\- Fournir une API REST avec Spring Boot

\- Stocker les données dans une base de données MySQL/MariaDB



\## 3. Acteurs



\### Client

\- Consulter les véhicules disponibles

\- Effectuer une demande de location

\- Consulter ses locations



\### Agent d'agence

\- Gérer les clients

\- Gérer les véhicules

\- Gérer les locations

\- Mettre à jour les informations des véhicules



\### Responsable d'agence

\- Superviser les activités de l'agence

\- Consulter les locations

\- Suivre les véhicules et les clients



\### Administrateur

\- Gérer les utilisateurs

\- Gérer les agences

\- Administrer le système

\- Superviser les données de l'application



\## 4. Technologies
